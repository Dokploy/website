Each database type has its own group: `postgres`, `mysql`, `mariadb`, `mongo` and `redis`.

## Requirements

You need to be [authenticated](/docs/cli/authentication) with the Dokploy CLI.

## Commands

All the database groups share the same actions. Replace `<group>` with the database type and `<id>` with the matching ID option (`--postgresId`, `--mysqlId`, `--mariadbId`, `--mongoId` or `--redisId`).

| Command | Description |
| --- | --- |
| `dokploy <group> create` | Create a new database. |
| `dokploy <group> one <id>` | Get the details of a database. |
| `dokploy <group> search` | Search databases. |
| `dokploy <group> deploy <id>` | Deploy a database. |
| `dokploy <group> start <id>` | Start a database. |
| `dokploy <group> stop <id>` | Stop a running database. |
| `dokploy <group> rebuild <id>` | Rebuild a database. |
| `dokploy <group> update <id>` | Update the settings of a database. |
| `dokploy <group> save-environment <id> --env <value>` | Save the environment variables of a database. |
| `dokploy <group> save-external-port <id> --externalPort <port>` | Set the external port of a database. |
| `dokploy <group> move <id> --targetEnvironmentId <id>` | Move a database to another environment. |
| `dokploy <group> remove <id>` | Delete a database. |

## Creating a database

The required options depend on the database type:

| Group | Required options |
| --- | --- |
| `postgres` | `--name`, `--databaseName`, `--databaseUser`, `--databasePassword`, `--environmentId` |
| `mysql` | `--name`, `--databaseName`, `--databaseUser`, `--databasePassword`, `--environmentId` |
| `mariadb` | `--name`, `--databaseName`, `--databaseUser`, `--databasePassword`, `--environmentId` |
| `mongo` | `--name`, `--databaseUser`, `--databasePassword`, `--environmentId` |
| `redis` | `--name`, `--databasePassword`, `--environmentId` |

All of them also accept `--appName`, `--dockerImage`, `--description` and `--serverId`.

## Examples

```bash
# Create a postgres database
dokploy postgres create \
  --name "my-db" \
  --databaseName app \
  --databaseUser app \
  --databasePassword "a-strong-password" \
  --environmentId env123

# Deploy it
dokploy postgres deploy --postgresId pg123

# Stop a redis database
dokploy redis stop --redisId redis123

# Delete a mysql database
dokploy mysql remove --mysqlId mysql123
```
